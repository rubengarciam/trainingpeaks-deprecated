# OpenClaw TrainingPeaks Skill

Openclaw skill to pull real-time training plans, workouts, fitness metrics (CTL/ATL/TSB), and personal records from TrainingPeaks. Uses cookie-based authentication (no API key needed). 
Use in conjunction with other endurance, cycling, running or swimming triathlon coach skills for best results.

- Read [SKILL.MD](SKILL.MD) for more info
- Published in [clawhub.ai](https://clawhub.ai/rubengarciam/trainingpeaks)
- Inspired by [JamsusMaximus/trainingpeaks-mcp](https://github.com/JamsusMaximus/trainingpeaks-mcp)
